Chapterly

Settings

The local Chapterly backend. Default: http://localhost:8080. The extension has host permission for localhost:8080 and 127.0.0.1:8080; any other address works only through the backend's CORS settings.

Only needed when the backend sets CHAPTERLY_API_TOKEN (for example when another laptop reaches it over Tailscale). Enter the same value; it is sent as X-Chapterly-Token with every request. Stored on this computer only, never synced. Leave empty for a local backend without a token.

Kokoro runs locally and is the default. Microsoft Azure voices appear when the backend has Azure credentials. If the chosen voice's provider fails, the backend may fall back to another provider.

1x

Also adjustable in the popup while reading. Changing it never re-requests audio.

While a chapter is being read, Chapterly takes over the page's arrow keys (some sites use them for chapter navigation). Keys are ignored while you type in a field.

    Chapterly remembers where you stopped in each novel.

    Finished audio is kept on this computer (at most 150 MB), so resuming after a long pause, going back and reading a chapter again need no new request.
