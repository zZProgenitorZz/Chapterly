The local Chapterly backend. Default: http://localhost:8080. The extension has host permission for localhost:8080 and 127.0.0.1:8080; any other address works only through the backend's CORS settings.

Kokoro runs locally and is the default. Microsoft Azure voices appear when the backend has Azure credentials. If the chosen voice's provider fails, the backend may fall back to another provider.
